# HUT RI ke-81 — PT Teknologi Kartu Indonesia

Aplikasi microsite event HUT RI ke-81 PT TKI.

## Stack
- Vite + React (JavaScript, bukan TypeScript)
- Tailwind CSS v4 (`@tailwindcss/vite`)
- GSAP + ScrollTrigger untuk animasi
- Logo vektor HUT RI 81 & PT TKI (SVG)

## Script
- `bun run dev` — dev server
- `bun run build` — production build
- `bun run lint` — oxlint
