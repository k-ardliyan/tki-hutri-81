# HUT RI ke-81 — PT Teknologi Kartu Indonesia x PT Fokus Teknologi Pembayaran

Aplikasi microsite event HUT RI ke-81 kolaborasi PT TKI x PT FTP.

## Stack
- Vite + React (JavaScript, bukan TypeScript)
- Tailwind CSS v4 (`@tailwindcss/vite`)
- GSAP + ScrollTrigger untuk animasi
- Logo vektor HUT RI 81, PT TKI, & PT FTP (SVG)

## Script
- `bun run dev` — dev server
- `bun run build` — production build
- `bun run lint` — oxlint
